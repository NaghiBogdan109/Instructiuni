Windows 8 / 8.1

Ghidul este valabil pentru Windows 8, Windows 8 Pro, Windows 8.1 și Windows 8.1 Pro. Cheia trebuie să fie pentru aceeași ediție ca cea instalată (Pro sau fără Pro).

Erori comune în timpul activării:

  • 0xC004F050 – cheia nu se potrivește cu ediția instalată. Verificați dacă aveți instalată ediția Pro sau ediția simplă, aceeași ca a cheii.
  • 0xC004C008 – cheia a fost deja folosită online. Folosiți activarea telefonică de mai jos.

Activare Online

1. Apăsați tastele Windows + R, scrieți comanda de mai jos și apăsați Enter.

slui 3

2. Introduceți cheia de licență primită. Dacă cheia este corectă, butonul Activare devine disponibil.

3. Apăsați Activare și așteptați confirmarea. Windows este activat.

Activare Telefonică

1. Apăsați tastele Windows + R, scrieți comanda de mai jos și apăsați Enter.

slui 4

2. Selectați țara și apăsați Următorul. Pe ecran apare ID-ul de instalare.

3. Accesați site-ul de mai jos și introduceți ID-ul de instalare afișat în fereastra de activare.

GetCID

4. Apăsați pe Get confirmation ID pentru a obține ID-ul de confirmare.

5. Apăsați pe Introduceți ID-ul de confirmare, completați ID-ul primit și apăsați Activare.

6. Reporniți calculatorul. Windows este activat.
