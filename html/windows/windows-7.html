Windows 7

Ghidul este valabil pentru Windows 7 Home Premium, Professional și Ultimate (SP1). Cheia trebuie să fie pentru aceeași ediție ca cea instalată.

  • Windows 7 Professional SP1ISO 64-bitISO 32-bit
  • Windows 7 Ultimate SP1ISO 64-bitISO 32-bit

Kiturile de mai sus sunt imaginile originale Microsoft (MSDN), disponibile doar în limba engleză. Pentru Home Premium folosiți kitul Ultimate: după ce îl copiați pe stick-ul de instalare, ștergeți fișierul sources\ei.cfg de pe stick, iar la instalare veți putea alege ediția Home Premium.

Activare Online

1. Faceți clic pe Start, apoi clic dreapta pe Computer și alegeți Proprietăți.

2. În partea de jos a ferestrei, la secțiunea Activare Windows, apăsați pe Modificare cheie produs (sau Activați Windows acum).

3. Introduceți cheia de licență primită și apăsați Următorul.

4. Așteptați câteva secunde. Când apare mesajul „Activare reușită”, Windows 7 este activat.

Activare Telefonică

1. Dacă activarea online nu reușește, apăsați tastele Windows + R, scrieți comanda de mai jos și apăsați Enter.

slui 4

2. Selectați țara și apăsați Următorul. Pe ecran apare ID-ul de instalare (9 grupuri de cifre).

3. Accesați site-ul de mai jos și introduceți ID-ul de instalare afișat în fereastra de activare.

GetCID

4. Apăsați pe Get confirmation ID pentru a obține ID-ul de confirmare.

5. Introduceți ID-ul de confirmare primit în câmpurile de sub ID-ul de instalare și apăsați Următorul.

6. Reporniți calculatorul. Windows 7 este activat.
