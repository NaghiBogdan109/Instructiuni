Windows Server RDS CAL

Ghidul este valabil pentru licențele RDS CAL (per utilizator sau per dispozitiv) pentru Windows Server 2008 R2 – 2025. Versiunea licențelor trebuie să fie aceeași sau mai nouă decât versiunea Windows Server pe care rulează serviciile Remote Desktop.

Instalarea licențelor

1. Asigurați-vă că serverul are instalat rolul Remote Desktop Services cu serviciul Remote Desktop Licensing (Server Manager → Add Roles and Features).

2. Deschideți Server Manager → Tools → Remote Desktop Services → Remote Desktop Licensing Manager.

3. Dacă serverul de licențe apare ca neactivat, faceți clic dreapta pe numele lui → Activate Server și urmați asistentul, cu metoda de conectare Automatic connection.

4. Faceți clic dreapta pe numele serverului → Install Licenses → Next.

5. La „License program” alegeți Retail purchase și apăsați Next.

6. Introduceți codul de licență primit (25 de caractere), apăsați Add, apoi Next și Finish. Licențele apar în listă, cu numărul de utilizatori sau dispozitive.

Setarea modului de licențiere

1. Deschideți Server Manager → Remote Desktop Services → Overview → Tasks → Edit Deployment Properties → RD Licensing.

2. Alegeți modul care corespunde licențelor: Per User pentru licențe per utilizator sau Per Device pentru licențe per dispozitiv. Adăugați serverul de licențe și apăsați OK.

Fără un deployment RDS, aceleași setări se fac din Group Policy: Computer Configuration → Administrative Templates → Windows Components → Remote Desktop Services → Remote Desktop Session Host → Licensing.

3. Verificați configurarea din Tools → Remote Desktop Services → RD Licensing Diagnoser. Dacă nu apar avertismente, licențele sunt active.
