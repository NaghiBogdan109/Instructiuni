Windows Server 2016 – 2025

Ghidul este valabil pentru Windows Server 2016, 2019, 2022 și 2025, edițiile Standard și Datacenter. Cheia trebuie să fie pentru aceeași versiune și ediție ca cea instalată.

  • Windows Server 2025ISO (English)Evaluation Center
  • Windows Server 2022ISO (English)Evaluation Center
  • Windows Server 2019ISO (English)Evaluation Center
  • Windows Server 2016ISO (English)Evaluation Center

Kiturile de mai sus sunt versiunile de evaluare oficiale Microsoft. La instalare alegeți ediția cheii (Standard sau Datacenter, cu Desktop Experience), apoi convertiți-o cu cheia, ca în secțiunea „Conversie din versiunea de evaluare”.

Activare cu cheia de produs

1. Deschideți Command Prompt ca administrator (clic dreapta pe Start → Command Prompt (Admin) / Terminal (Admin)).

2. Verificați ediția instalată. Dacă în rezultat apare Evaluation, urmați întâi secțiunea „Conversie din versiunea de evaluare” de mai jos.

DISM /online /Get-CurrentEdition

3. Introduceți cheia de produs (înlocuiți X-urile cu cheia primită):

slmgr /ipk XXXXX-XXXXX-XXXXX-XXXXX-XXXXX

4. Activați online:

slmgr /ato

5. Verificați starea licenței. La „License Status” trebuie să apară Licensed.

slmgr /dlv

Conversie din versiunea de evaluare

1. Versiunea de evaluare nu acceptă direct o cheie de produs. Vedeți în ce ediții poate fi convertită:

DISM /online /Get-TargetEditions

2. Rulați conversia cu cheia primită. Folosiți ServerStandard sau ServerDatacenter, după ediția cheii:

DISM /online /Set-Edition:ServerDatacenter /ProductKey:XXXXX-XXXXX-XXXXX-XXXXX-XXXXX /AcceptEula

Versiunea de evaluare Datacenter se poate converti doar în Datacenter; versiunea de evaluare Standard se poate converti în Standard sau Datacenter.

3. Reporniți serverul când vi se cere (poate reporni de două ori). Apoi activați cu slmgr /ato, ca în secțiunea de mai sus.

Activare Telefonică

1. Dacă slmgr /ato returnează o eroare, afișați ID-ul de instalare:

slmgr /dti

2. Accesați site-ul de mai jos și introduceți ID-ul de instalare afișat în fereastra deschisă de comandă.

GetCID

3. Apăsați pe Get confirmation ID pentru a obține ID-ul de confirmare.

4. Introduceți ID-ul de confirmare primit (fără spații sau cratime):

slmgr /atp ID_DE_CONFIRMARE

5. Verificați cu slmgr /dlv că starea este Licensed. Serverul este activat.
